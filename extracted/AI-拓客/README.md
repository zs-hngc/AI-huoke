# AI-拓客（科航 AI 超级员工 · 复刻协作版）

> 一个**零依赖**的 AI 拓客 Web 系统：把"找客户 → 解析线索 → 管客户 → AI 辅助回复"串成一条可协作的工作流。
> 本目录为团队交付包，包含完整源码、进度记录与部署文档。

## 一、系统定位

复刻"科航 AI 超级员工"中「拓客」相关业务能力，落地为一个本地可跑的 Web 应用。
**合规底线（全员必须遵守）**：不爬取、不模拟点击、不自动发送消息；所有"获取"与"回复"动作均由真人完成，AI 只做解析、分级与草稿生成。

## 三、技术架构

- **后端**：`server.js`，**零依赖** Node.js（仅用内置 `http`/`fetch`/`fs`/`crypto`），无需 `npm install`。
- **数据层**：`db.js` + Node 内置 `node:sqlite`，DB 文件 `data/app.db`（**WAL 模式**）。2026-08-03 起由 JSON 文件迁移而来。
  - ⚠️ **启动必须带 `--experimental-sqlite` 标志**（Node 22 下该模块仍是实验特性）：`npm start` 已包含该标志。
  - `xiaoguan` / `kefu` / `renshi` 三个演示模块仍使用 `data/*.json`，尚未迁移。
- **前端**：`index.html` + `style.css` + `app.js`，单页应用（SPA），无构建步骤。
- **外部依赖**：DeepSeek（AI）、高德地图 Web 服务（POI/行政区划）、Leaflet（地图渲染，CDN 引入）。
- **坐标系**：高德 GCJ-02，地图标记直接使用，无需转 WGS-84。

## 五、30 秒上手

```bash
cd ai-tuoke
cp .env.example .env        # 填入你自己的 DeepSeek / 高德 Key
npm start                   # 等价于 node --experimental-sqlite server.js
# 浏览器打开 http://localhost:3000
# 默认登录:
#   admin / admin123（管理员）
#   sales / sales123（销售）
```

> 首次登录后建议尽快修改默认密码；生产环境还应放在内网或加反向代理。当前会话为服务端内存存储，**服务重启后需重新登录**。

详细步骤见 **部署与运行.md**。进度与合规见 **项目进度.md**。
