# 团队协作说明

本目录是一份**可直接分享给团队**的 AI-拓客交付包。以下约定帮助多人顺畅协作。

## 一、仓库初始化（拿到包之后）

```bash
cd AI-拓客
git init
git add .
git commit -m "init: AI-拓客 协作包"
# 推到你们的团队仓库（GitLab / Gitee / GitHub ...）
```

> `.env` 与 `data/` 已在 `.gitignore` 中，**不会被提交**。每个人 clone 后自己 `cp .env.example .env` 填密钥。

## 二、目录与改动规范

- **源码只在 `ai-tuoke/` 里改**：`server.js`（后端）、`index.html` / `app.js` / `style.css`（前端）。前端是纯静态 SPA，无构建步骤。
- **新增弹窗必带隐藏**：任何用 `.modal-overlay` / `.drawer-overlay` 类的弹窗，HTML 必须加 `style="display:none"`，否则默认 `flex` 全屏遮罩会挡住所有点击（前车之鉴，见 `项目进度.md` 第三节）。
- **密钥绝不入库**：只改 `.env`，且 `.env` 已被 gitignore。不要把 Key 贴进代码、文档、聊天记录。
- **运行时数据不入库**：`ai-tuoke/data/*.json` 含真实客户/线索，已 gitignore。

## 三、环境管理

- 每人本地一份 `.env`，**不共享**。模板见 `.env.example`。
- DeepSeek / 高德 Key 各自申请各自的；团队共用 Key 易触发限流且难追责，不建议。

## 四、如何自测（含中文相关）

- **启动**：`cd ai-tuoke && node server.js`，访问 `http://localhost:3000`。
- **前端改完强刷**：`Ctrl+Shift+R` 清缓存。
- **接口测试用 Python（重要）**：命令行中文在 Git Bash（GBK）下会被破坏，导致"状态没更新"等**假失败**。验证中文接口请一律用 UTF-8 的 Python（见 `部署与运行.md` 思路），或用带 UTF-8 终端的 curl。
- **平台接入自测**：用「模拟推送」按钮，无需凭证即可验证 AI 分级 → 线索池 → 入库全链路。

## 五、提交流程建议

1. 从 `main` 切特性分支：`git checkout -b feat/xxx`
2. 本地自测通过（含上面 Python 验证）
3. PR 到 `main`，描述"改了什么 / 验证了什么"
4. 涉及合规边界（爬虫/模拟点击/自动发送）的改动**一律拒绝**

## 六、ℹ️ 重要风险提示

- 本项目**严格合规**：获取与回复动作都由真人完成。任何"自动化抓取私信/评论"的需求，请引导走官方开放平台路径，不要接爬虫方案。
- 客户隐私数据注意脱敏，不要在公开仓库或第三方 IM 里粘贴 `data/*.json` 内容。
