## 客户管理上线后 Bug 修复（19:53 用户反馈）
- **症状**：进客户管理页后无法点侧边栏跳转其他页；新增客户后无法删除。
- **根因 1（两个 bug 的共同原因）**：新增的 `custModal`(#1713)、`custDrawer`(#1786) 的 HTML **缺少内联 `style="display:none"`**，而 CSS `.modal-overlay`/`.drawer-overlay` 默认 `display:flex` + `position:fixed;inset:0` + z-index 2000/2100（高于侧边栏 900）。于是两个全屏半透明遮罩从页面加载起就一直盖住整屏，拦截所有点击（侧边栏跳转、表格删除按钮全被挡）。原 `aiGenModal`/`notificationModal` 都带了 `style="display:none"` 所以之前不报错——这是我加新弹窗时遗漏的。
- **根因 2（删除静默失败）**：`deleteCust` 用原生 `confirm()`，嵌入式预览可能禁用原生 dialog 导致返回 falsy 而 `return` 跳过删除。已改为自定义确认弹窗 `#confirmModal`（`showConfirm()` 返回 Promise，`closeConfirm(result)` 解析），`deleteCust` 内 `await showConfirm(...)`。
- **修复动作**：index.html 给 `#custModal`/`#custDrawer` 加 `style="display:none"`，新增 `#confirmModal`（含取消/确定）；app.js 加 `showConfirm/closeConfirm`，删除 `confirm()` 调用；给 `custDrawer` 遮罩加 `onclick="if(event.target===this)closeCustDrawer()"` 点空白关闭。
- **验证**：`node --check` 通过；Python 走 `POST 创建 → DELETE 删除 → GET 校验已消失` 全链路 ok；curl 确认线上 index.html 已含三处修复标记。服务无需重启（静态文件每次请求实时读取）。
- **重要教训**：用 `.modal-overlay`/`.drawer-overlay` 类的新弹窗，HTML 必须带 `style="display:none"` 初始隐藏，否则默认 flex 会全屏挡点击。后续加任何弹窗都要遵守。
